# Автопостинг: Telegram → VK, Threads, Дзен

Раз в 15 минут GitHub Actions забирает новые посты из Telegram-канала и
публикует их в группу VK и в Threads, а также обновляет RSS-фид, который
периодически (раз в 2-5 минут) сам вычитывает Дзен.

## Как это устроено

1. `fetch_telegram.py` — читает новые посты канала через Telegram Bot API
   (бот должен быть админом канала), скачивает фото/видео.
2. Медиа коммитится в `docs/media/` и пушится — эта папка отдаётся наружу
   через GitHub Pages.
3. `post_vk.py` — публикует пост на стену группы VK (фото/видео грузятся
   напрямую, без публичного URL).
4. `post_threads.py` — публикует пост в Threads через официальный Threads
   API (нужен публичный URL картинки/видео — поэтому шаг идёт после
   пуша медиа). Если в посте несколько фото, в Threads уйдёт только первое.
5. `update_dzen_feed.py` — генерирует HTML-страницу поста и пересобирает
   `docs/dzen.xml`. Сама публикация в Дзен происходит НЕ через API (его
   не существует), а через то, что Дзен сам периодически скачивает этот
   RSS-файл и импортирует из него новые материалы.

Всё состояние (что уже опубликовано, offset Telegram и т.д.) хранится в
`state/*.json` и коммитится обратно в репозиторий — так следующий запуск
не публикует посты повторно.

## ⚠️ Репозиторий публичный — это осознанно

GitHub Pages бесплатно отдаёт статические файлы только из публичных
репозиториев, а Дзену и Threads нужны публичные ссылки на медиа. Значит:

- **Никогда не вставляйте токены в код или в issues/PR** — только в
  Settings → Secrets. Логи Actions в публичном репозитории видны всем.
- Все фото и видео, которые вы публикуете в Telegram-канал, окажутся
  доступны по прямой ссылке всем в интернете (как и в самом канале/VK).

## Что нужно настроить один раз

### 1. Secrets репозитория
Settings → Secrets and variables → Actions → New repository secret:

| Secret | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHANNEL_ID` | id канала (например `-1001234567890`) или `@username` |
| `VK_ACCESS_TOKEN` | ключ доступа сообщества VK (права: wall, photos, video) |
| `VK_GROUP_ID` | id группы VK (число, без минуса) |
| `THREADS_ACCESS_TOKEN` | long-lived токен Threads API (живёт ~60 дней, см. ниже) |
| `THREADS_USER_ID` | Threads user id, который вернул OAuth |

### 2. GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`,
папка **/docs** → Save. Через минуту сайт появится по адресу вида
`https://<ваш-аккаунт>.github.io/asya-social-autopost/`.

### 3. Telegram-бот
1. В Telegram напишите @BotFather → `/newbot`, получите токен.
2. Добавьте бота администратором в канал (без права публиковать —
   только чтение сообщений).

### 4. VK
Права администратора сообщества → «Управление» → «Работа с API» →
создать ключ доступа с правами `wall`, `photos`, `video`.

### 5. Threads (Meta)
1. developers.facebook.com → создать приложение → добавить продукт
   **Threads API**.
2. В App roles добавить свой аккаунт как Threads tester (тогда App
   Review не нужен — это только для публикации от чужого имени).
3. Пройти OAuth (`threads.net/oauth/authorize` → обмен кода на токен →
   апгрейд до long-lived token на 60 дней).
4. **Токен нужно обновлять** методом `refresh_access_token` до того, как
   истечёт 60 дней (обновлять можно раз в 24+ часа). Это не
   автоматизировано в этом репозитории — проще всего попросить меня
   поставить напоминание, чтобы не забыть.

### 6. Дзен
В кабинете Дзена → настройки канала → импорт по RSS → указать
`https://<ваш-аккаунт>.github.io/asya-social-autopost/dzen.xml`.
Файл появится только после первого успешного запуска workflow.

## Первый запуск

Actions → Autopost → Run workflow (кнопка справа) — запускает вручную,
не дожидаясь расписания. Дальше он идёт сам каждые 15 минут.

## Ограничения, о которых стоит знать

- Из альбома в Threads уходит только первая фотография.
- Отредактированные задним числом посты в Telegram не подхватываются
  (учитываются только новые сообщения).
- Threads-токен требует ручного продления примерно раз в 1,5-2 месяца.
- Если Дзен требует подтверждения владения доменом/сайтом для полноценного
  импорта — это отдельная настройка в его кабинете, я не могу сделать её
  за вас.
